# Project 1: Live SOC Alert Monitoring (LetsDefend)

## Tujuan
Latihan triage alert secara real-time kayak analyst SOC Tier 1 beneran — deteksi, klasifikasi, dan respons terhadap security event di platform LetsDefend.

## Skill yang Dilatih
- Alert triage (True Positive vs False Positive)
- Log analysis dasar
- Escalation decision-making
- Dokumentasi insiden

## Tools
- LetsDefend (free tier)

## Ringkasan Kerjaan
> Isi setelah selesai — berapa alert yang di-handle, jenis alert apa aja (phishing, malware, brute force, dll), berapa yang True Positive.

Contoh format:
| No | Alert Type | Klasifikasi | Aksi | Catatan |
|----|-----------|-------------|------|---------|
| 1  | Suspicious Login | True Positive | Block IP, notify user | Login dari negara asing di luar jam kerja |
| 2  | ... | ... | ... | ... |
