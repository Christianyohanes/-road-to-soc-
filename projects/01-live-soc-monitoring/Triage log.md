# Triage Log — Live SOC Monitoring

Catat setiap alert yang lo handle di sini secara kronologis. Ini bukti kerja harian lo, sekaligus bahan buat nulis resume bullet nanti.

## Format per Entry
```
### [Tanggal] - Alert #[nomor]
- Alert Name: 
- Severity: (Low/Medium/High/Critical)
- Source: (misal: Endpoint, Email Gateway, Firewall)
- Waktu deteksi: 
- Waktu response: 
- Klasifikasi: True Positive / False Positive / Benign
- Ringkasan singkat: 
- Status: Closed / Escalated
```
